# SoloScraper

ابزار استخراج محتوای وب با قابلیت شناسایی خودکار نوع فایل‌ها، خزش هوشمند و مدیریت حجم دانلود.

## قابلیت‌ها

- **خزش خودکار وب‌سایت‌ها** با قابلیت تعیین عمق جستجو و محدودیت دامنه
- **پشتیبانی از محتوای داینامیک** از طریق Selenium برای وب‌سایت‌های مبتنی بر جاوااسکریپت
- **شناسایی خودکار نوع فایل** بر اساس پسوند و هدرهای HTTP
- **استخراج محتوای متنی** از صفحات وب شامل تیترها، پاراگراف‌ها، لیست‌ها و محتوای اصلی
- **مدیریت حجم دانلود** با قابلیت تعیین حداکثر حجم مجاز
- **خروجی ZIP** با ساختار پوشه‌بندی شده بر اساس نوع محتوا
- **نمایش پیشرفت** دانلود با نوار پیشرفت و گزارش‌دهی دقیق

## ساختار پروژه

```

SoloScraper/
├── main.py              # نقطه ورود برنامه
├── scraper.py           # مدیریت خزش و استخراج محتوا
├── downloader.py        # مدیریت دانلود فایل‌ها
├── content_detector.py  # تشخیص نوع محتوا
├── README.md            # مستندات
├── LICENSE              # لایسنس
└── requirements.txt     # وابستگی‌های پروژه

```

## نصب و راه‌اندازی

### پیش‌نیازها

- Python 3.8 یا بالاتر
- Chrome/Chromium (برای استفاده از Selenium)

### نصب وابستگی‌ها

```bash
pip install -r requirements.txt
```

### اجرای برنامه

```bash
python main.py
```

### راهنمای استفاده

پس از اجرای برنامه، از شما اطلاعات زیر خواسته می‌شود:

1. آدرس وب‌سایت: آدرس کامل یا نسبی وب‌سایت مقصد
2. نام فایل خروجی: نام فایل ZIP نهایی (بدون پسوند)
3. حداکثر حجم دانلود: حداکثر حجم کل دانلودها بر حسب مگابایت
4. عمق خزش: تعداد سطح‌های جستجو (بین ۱ تا ۵)
5. استفاده از Selenium: فعال‌سازی برای وب‌سایت‌های جاوااسکریپتی

### ساختار خروجی

فایل ZIP تولید شده شامل پوشه‌های زیر است:

```
temp_downloads/
├── texts/       # فایل‌های متنی و محتوای استخراج شده
├── pdfs/        # فایل‌های PDF
├── codes/       # فایل‌های کد منبع
├── images/      # تصاویر
├── videos/      # ویدئوها
├── audios/      # فایل‌های صوتی
├── archives/    # فایل‌های فشرده
└── unknown/     # فایل‌های با نوع نامشخص
```

## معماری سیستم

### Scraper

کلاس اصلی خزش و استخراج محتوا. وظایف:

· مدیریت کوئین خزش با صف و عمق مشخص

· دریافت محتوای صفحات از طریق Requests یا Selenium

· استخراج لینک‌های صفحات و فایل‌ها

· استخراج محتوای متنی ساختاریافته از صفحات


### Downloader

مدیریت فرآیند دانلود:

· دانلود با نمایش نوار پیشرفت

· مدیریت حجم کل دانلودها

· تأخیر بین درخواست‌ها برای جلوگیری از مسدود شدن

· مدیریت خطاهای شبکه


### ContentDetector

تشخیص خودکار نوع محتوا:

· تشخیص بر اساس پسوند فایل

· تشخیص بر اساس هدر Content-Type

· پشتیبانی از انواع: متن، کد، PDF، تصویر، ویدئو، صدا، آرشیو


## وابستگی‌ها

| کتابخانه | کاربرد |
|-----------|--------|
| `requests` | درخواست‌های HTTP |
| `beautifulsoup4` | پردازش HTML |
| `selenium` | تعامل با صفحات جاوااسکریپتی |
| `webdriver-manager` | مدیریت درایور Chrome |
| `tqdm` | نمایش نوار پیشرفت |
| `colorama` | رنگ‌آمیزی خروجی کنسول |

## نکات اجرایی

· برای وب‌سایت‌های با محتوای داینامیک، فعال‌سازی Selenium توصیه می‌شود

· در حالت Selenium، مرورگر در حالت Headless اجرا می‌شود

· تأخیر ۰٫۵ ثانیه‌ای بین درخواست‌ها برای جلوگیری از بار سنگین روی سرور

· لینک‌های تکراری و خارج از دامنه در حالت پیش‌فرض نادیده گرفته می‌شوند


## مدیریت خطا

· خطاهای شبکه با پیام مناسب گزارش می‌شوند

· در صورت خطا در دانلود یک فایل، سایر دانلودها ادامه می‌یابند

· در صورت رسیدن به حجم مجاز، دانلود متوقف می‌شود

· خطاهای مربوط به Selenium به حالت Requests برگشت داده می‌شوند
